# Next.js Reference Index

Use this folder for Next.js app structure, UI/backend boundaries, route handlers, prompts, and version-sensitive behavior.

General code style lives in `../senior-dev/workflow.md`; this folder only adds Next.js-specific rules.

## Route by task

| Task signal | Read |
| --- | --- |
| Any Next.js code change | `version-check.md` and `structure.md`, then task file |
| UI components or frontend calls | `ui.md` |
| API endpoints or route handlers | `api-routes.md` |
| Routing, route groups, layouts, pages | `routing.md` |
| LLM prompts or config files | `prompts-config.md` |
