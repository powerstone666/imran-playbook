# Next.js Version Check

This is NOT necessarily the Next.js version you know.

This version may have breaking changes. APIs, conventions, and file structure may differ from training data.

Before writing Next.js code:

1. Check the installed version in `package.json` (or `node_modules/next/package.json`).
2. If `node_modules/next/dist/docs/` exists, read the relevant guide there.
3. Otherwise, consult the official Next.js docs for that exact version.

Heed deprecation notices and local project conventions.
